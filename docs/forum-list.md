# Форумный список

`/forum/list` формирует BBCode без публикации на форум. Уровни 1+ читают и копируют;
7+ редактируют общий шаблон, соответствия и импортируют старые токены. Права
проверяются backend, включая предпросмотр несохранённого шаблона.

## Данные и шаблон

Источник — фиксированный `https://r-arrow.ru/api/v1`: `/me`, `/fractions`,
`/leaders`, `/judges`, `/ministers`, `/administration`, `/rate-limit`.
Пагинация загружается полностью; люди объединяются по `leader_id`.
Снимок публикуется целиком, предыдущий сохраняется при ошибке.
TTL — пять минут, общая DB lease исключает параллельные обновления.
Лимит — восемь учитываемых запросов за минуту с обработкой бюджета и 429.

Начальный BBCode находится в `backend/app/assets/forum_list_default.bbcode`:
15 таблиц, 76 мест, оформление предоставленного пользователем образца.
Администрация, нелегальные организации и министры доступны в каталоге, но не
вставляются в этот образец. Отдельное место вице-губернатора выводит «—», если
API не обозначает эту должность явно. Заместитель автоматически его не занимает.

Примеры: `{{fraction.1.leaders.1.nickname}}`,
`{{fraction.1.deputies.2.vk_link}}`, `{{judges.1.post_date}}`, `{{generated_at}}`.
Номера мест начинаются с 1; повторение токена возвращает того же человека.
Пустое подтверждённое место — «Вакантно», отсутствующее поле — «—».
`planned_end_date` вычисляется из назначения и срока; это не дата снятия.
Время формирования — МСК. BBCode-значения экранируются, URL проверяются.
Неизвестные поля внешнего API автоматически не публикуются.
`role_stage` администрации не связан с уровнями доступа панели; контакты,
которых нет в ответе администрации, в каталог не добавляются.

Если у человека отсутствует VK в API, контакт берётся из действующего местного
реестра руководителей только при единственном совпадении нормализованного ника,
организации и должности. Также допускается зарегистрированный аккаунт уровня 0
с явным тегом организации/ранга без флага руководителя, если текущий API
подтверждает то же назначение и после регистрации нет закрытого назначения.
Это только получение контакта: должности и права не меняются.
Контакт API имеет приоритет. Следящие не участвуют. Соответствия сокращений:
SFFD → DES, FP → MSP. Неизвестные соответствия министерств не угадываются.
Резервные контакты берутся из текущего реестра при формировании и предпросмотре,
без ожидания обновления r-arrow и без записи поверх внешнего снимка.
Нулевой или некорректный VK ID не блокирует резервный поиск. Готовые VK-ссылки
используют BBCode без кавычек; старые сохранённые шаблоны поддерживаются.

## Настройки и безопасность

Ключ задаёт разработчик: «Настройки → Интеграции → Форумный список».
Поле только для записи. Новый ключ проверяется через `/me` до атомарной замены
серверного `.env`. Ошибка оставляет прежний ключ. Ключ не возвращается API,
не включается в аудит, frontend storage или диагностические сообщения.
Секреты бота и рабочая БД бота этой функцией не изменяются.

`ForumListSettings` и `ForumListSnapshot` принадлежат panel.db. Миграция
`forum_list_v1` создаёт полную резервную копию до генерации таблиц; запись в
`panel_migrations` завершает её однократно. Сохранение шаблона защищено версией
(409 при конфликте). Аудит содержит метаданные, без текста шаблона и ключа.
Черновик шаблона защищён при навигации и хранится в sessionStorage.

API: `/api/forum/list`, `/settings`, `/render`, `/refresh`, `/import`;
управление ключом — `/api/dev/forum-list-key`.

## Проверка

`backend/scripts/test_forum_list.py` использует временные базы и подменённый HTTP.
`frontend/scripts/check-forum-list.mjs` проверяет права, формы, конфликт версий,
импорт, ключ и размеры 390/768/1440 px; операции изменения подменяются.
Регрессия назначений — `backend/scripts/test_staff_appointments.py`.
Назначенные следящие и руководители исключены из вкладок участников без
назначения независимо от бесед; чтение реестров не меняет назначения.

Изменения проверяются локально на frontend 5173 и API 8012. Рабочий сервер
автоматически не обновляется.

Для диагностики зарегистрированных людей, ошибочно отображаемых без назначения:
`python backend/scripts/diagnose_leader_assignments.py Tatsuki_Nishimura Mila_Inadequste Lavanda_Skywalker`.
Запускать в окружении backend панели из корня репозитория. Скрипт только читает
уровень, флаг, сохранённую/распознанную должность и даты назначения/архивирования;
не выводит конфигурацию и секреты и ничего не восстанавливает по старому нику.
